What this page measures

Point-in-time checks of identity readiness, documentation and the service website, refreshed every 30 seconds. Identity readiness checks database reachability, schema and active realm keys. These checks run inside the same deployment and do not measure end-to-end Internet availability, independent worker/email delivery, historical uptime or an SLA.
